# ☕ Бот кафе «Уют»

Telegram-бот для кафе: показывает меню и контакты, принимает брони столиков.
Проект для портфолио: кафе, адрес и меню вымышленные.

## Что умеет

- **📋 Меню.** Категории кнопками (кофе, десерты, обеды), у каждой позиции название и цена.
- **📅 Бронь столика.** Бот по шагам спрашивает дату, время, число гостей и имя, показывает сводку и просит подтвердить.
- **🔔 Уведомление админу.** Подтверждённая заявка приходит администратору в Telegram и сохраняется в `bookings.json`.
- **📞 Контакты.** Адрес, телефон и часы работы.
- **❌ Отмена** доступна на любом шаге брони.

Бот проверяет ввод:
- дата не в прошлом и не дальше чем на 60 дней вперёд;
- время в часы работы и не позже чем за час до закрытия; если бронь на сегодня, время ещё не прошло;
- гостей от 1 до 20.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и главное меню |
| `/book` | Забронировать столик (то же, что кнопка) |
| `/cancel` | Отменить бронирование |
| `/help` | Справка |

## Запуск (Windows, PowerShell)

1. Создайте бота у [@BotFather](https://t.me/BotFather): команда `/newbot`, затем скопируйте токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot). На этот ID будут приходить брони.
3. Установите зависимости:
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
4. Создайте файл настроек из шаблона:
   ```powershell
   Copy-Item .env.example .env
   ```
   Откройте `.env` и впишите `BOT_TOKEN` и `ADMIN_ID`.
5. Запустите бота:
   ```powershell
   python bot.py
   ```
6. **Администратор должен один раз нажать `/start` у бота.** Без этого Telegram не разрешит боту писать ему первым. Если сообщение админу не дошло, заявка всё равно сохранится в `bookings.json`, а в консоли появится ошибка.

Остановить бота: `Ctrl+C`.

## Как поменять меню и контакты

Всё лежит в `menu.json`, код трогать не нужно:
- `cafe`: название, адрес, телефон, часы работы. `open_time` и `close_time` задают время, на которое можно бронировать.
- `categories`: категории. У каждой есть `id` (латиницей, без пробелов), `title` (подпись кнопки) и `items` (позиции с `name` и `price`).

Файл читается заново при каждом запросе, поэтому изменения видны без перезапуска бота.
Сохраняйте файл в кодировке UTF-8 и следите за запятыми: неправильный JSON сломает меню.

## Проверка без Telegram

```powershell
.venv\Scripts\python.exe -m unittest -v
```

Тесты проверяют разбор даты, времени, числа гостей и имени, сохранение в `bookings.json`, содержимое `menu.json`, а также весь сценарий брони на поддельных сообщениях: подтверждение, отмену и случай, когда админ недоступен.

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | Точка входа: кнопки, команды, пошаговая бронь |
| `booking.py` | Логика брони без Telegram: проверки, сводка, запись в `bookings.json` |
| `menu.py` | Чтение `menu.json` и оформление меню и контактов |
| `config.py` | Чтение `BOT_TOKEN` и `ADMIN_ID` из `.env` |
| `menu.json` | Меню и контакты кафе |
| `bookings.json` | Заявки. Создаётся автоматически и в git не попадает: там личные данные |
| `.env.example` | Шаблон настроек. Сам `.env` в git не попадает |
| `tests/` | Тесты |
